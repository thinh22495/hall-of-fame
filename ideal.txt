## 🎯 Chủ đề
Website kỷ niệm 10 năm công ty IT VHEC với concept:
"10 Years Together – Wall of Fame & Gratitude"

Mục tiêu:
- Tôn vinh hành trình 10 năm
- Tạo trải nghiệm cá nhân hóa cho từng nhân viên
- Gắn kết tinh thần đồng đội
- Deploy qua Vercel
- Người dùng có thể vào xem lại, sửa, tạo mới

---

## 🎨 Phong cách giao diện
- Dark mode hiện đại
- Tông màu xanh công nghệ (#0ff, #38bdf8), glow nhẹ
- Phong cách IT / futuristic – gợi cảm giác control room, starship
- Responsive cho desktop và mobile
- Animation fade-in nhẹ khi card xuất hiện
- Font hiện đại, dễ đọc (Inter hoặc Space Grotesk + JetBrains Mono cho số/năm)
- Layout single-page scroll

Màu sắc theo nhóm vai trò:
- Kỹ thuật       → xanh cyan   (#00d4ff)
- Thiết kế/SP    → tím         (#a855f7)
- Vận hành/HT    → vàng cam   (#f59e0b)

**Concept trực quan:**
Hình dung như một bầu trời đêm: mỗi nhân viên là một ngôi sao sáng,
cùng nhau tạo thành chòm sao của công ty.

**Nền section:**
- Background đen sâu với star particle CSS cố định (không cần canvas)
- Tiêu đề section: "✦ Bức tường Tri ân" + subtext "Những ngôi sao sáng của VHEC"

**Filter & Sort bar (dính trên cùng khi cuộn):**

- Mobile: 1 cột
- Mỗi card cùng kích thước, khoảng cách đều, không random chiều cao
  (giữ clean, tránh rối mắt)

**Mỗi mini-card:**

## 💾 Data Layer

**Supabase (primary):**
Table: `hall_of_fame_entries`
```
id            uuid        PK, default gen_random_uuid()
name          text        NOT NULL
role          text        NOT NULL
role_group    text        NOT NULL   -- 'tech' | 'design' | 'ops'
year          integer     NOT NULL   CHECK (year BETWEEN 2016 AND 2026)
milestone     text        NOT NULL
thank_you     text
avatar_color  text                   -- hex màu glow đã chọn
created_at    timestamptz DEFAULT now()
updated_at    timestamptz
```
RLS policy:
- SELECT: public (tất cả đọc được)
- INSERT: public (ai cũng tạo được)
- UPDATE/DELETE: chỉ khi client gửi đúng id (lưu id trong localStorage)

**LocalStorage (secondary / fallback):**
Key: `vhec_wall_of_fame_entries`
Chỉ lưu danh sách `{ id, name, role, year }` của máy hiện tại
→ nhận diện "card của mình" để hiện nút Sửa/Xóa
→ Nếu Supabase lỗi → fallback render từ localStorage

## 🧹 Yêu cầu code

Functions chính:
- `saveEntry(data)`              → POST Supabase, fallback localStorage
- `loadEntries(filter, page)`   → GET Supabase, fallback localStorage
- `renderHallOfFameCard(entry)` → render full card sau submit
- `renderThankYouWall(entries)` → render toàn bộ wall
- `appendCardToWall(entry)`     → prepend card mới + animate
- `highlightCard(id)`           → scroll + pulse highlight trong wall
- `openEntryModal(entry)`       → mở modal xem đầy đủ
- `downloadCard()`              → html2canvas → PNG
- `shareEntry(entry)`           → navigator.share / clipboard
- `filterWall(filters)`         → lọc + re-render wall
- `initCountUp()`               → animate Stats bar
- `initI18n(lang)`              → load JSON + apply text

Cấu trúc file:
```
├── index.html
├── css/
│   ├── main.css          # Reset, variables (--color-*, --glow-*, --radius-*)
│   ├── hero.css
│   ├── form.css
│   ├── card.css          # Hall of Fame card
│   ├── wall.css          # Thank You Wall + modal + skeleton
│   └── animations.css
├── js/
│   ├── config.js         # Supabase URL/key, constants, role→group map
│   ├── i18n.js           # Đa ngôn ngữ
│   ├── db.js             # saveEntry, loadEntries (Supabase + localStorage)
│   ├── render.js         # renderHallOfFameCard, renderThankYouWall, modal
│   ├── effects.js        # Confetti presets, particles, countUp, toast
│   ├── share.js          # downloadCard, shareEntry
│   └── main.js           # Init, event listeners
├── locales/
│   ├── vi.json           # Tiếng Việt
│   └── ja.json           # Tiếng Nhật
└── assets/
    ├── audio/            # Nhạc nền ambient/lo-fi
    └── sprites/          # SVG icons, logo VHEC
```

Quy tắc:
- Vanilla JS + CSS thuần, không dùng framework
- Thư viện cho phép: html2canvas CDN, Supabase JS CDN
- Comment ngắn cho mỗi function và section HTML chính
- CSS custom properties để dễ thay đổi theme
- Không inline style trong HTML
- Sẵn sàng deploy Vercel (static site, env vars qua vercel.json)
